<p align="center"><strong>Econometrics &amp; Mathematical Economics · LSE</strong><br>Causal inference, data science, and questions worth investigating.</p>
<p align="center"><a href="https://vigneshnara88.github.io/">Portfolio &amp; research notes</a> · <a href="https://github.com/vigneshnara88?tab=repositories">All repositories</a></p>

I'm interested in how we move from patterns in data to credible conclusions about policy. I work with Python, R, Stata and SQL, and enjoy building research tools alongside empirical projects.

My work spans labour markets, education, consumer complaints and multilingual language technology. I like projects that make the reasoning visible: the question, the data, the assumptions, and what the evidence can support.

## Selected work

| Project | What I'm working on |
| --- | --- |
| [CROWN Acts & labour markets](https://github.com/vigneshnara88/crown-acts-labour-market) | An independent paper on hair-discrimination protections, using ACS data and a triple-difference design. Python workflow and reported estimates. |
| [Consumer complaint language](https://github.com/vigneshnara88/consumer-complaints-language) | NLP research on template reuse, measurement and company-reported relief in CFPB complaints. Developed from DS202W coursework, with valuable feedback from Dr Ghita Berrada. Ongoing. |
| [SwitchF1](https://github.com/vigneshnara88/SwitchF1) | An ASR evaluation tool I developed through my agentic code-switching work. It applies precision, recall and F1 to language-switch events, complementing word error rate. |
| [Econometrics Game 2026](https://github.com/vigneshnara88/econometrics-game-2026) | Team research on education incentives and fertility. Our team placed **second**. Python and Stata analysis across two rounds. |
| [RD external validity / AIPW_RD](https://vigneshnara88.github.io/projects/rd-external-validity/) | Frontend and R/Python package development for an extension to RD designs. Core research ideas and direction: **Prof. Kirill Borusyak, Dr Luther Yap and Dr Sid George**. Research repository is private. |
| [Agentic code switching](https://github.com/vigneshnara88/code-switching-generation) | Rule-guided English–Tamil and Malay–English generation, annotation and review resources, motivated by how multilingual communities actually use language. |

## Questions I'm developing

- **[Schooling incentives & adolescent work](https://github.com/vigneshnara88/pe-de-meia-school-work):** a research proposal on Brazil's Pé-de-Meia programme, with sample-construction and study-design code.
- **[Adaptive visual-field testing](https://github.com/vigneshnara88/visual-field-adaptive-testing):** an exploratory simulation framework and reading list on statistical efficiency and the testing experience.
- **[Housing rules & building height](https://github.com/vigneshnara88/single-stair-housing):** public building-permit data and exploratory analysis of single-stair housing rules.
- **[Family background & education](https://github.com/vigneshnara88/ukhls-family-background):** an independent UKHLS/BHPS exploration of household relationships and observational-data challenges.
